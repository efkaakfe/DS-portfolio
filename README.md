# Data Science portfolio

This repository contains part of my Data Science projects:

*   Walmart sales prediction: prediction of Walmart sales per store based on the dataset from M5 competition
*   MLE Classification: multiclass classification within Docker container using Neural Networks
*   Sales prediction - Neural Networks: sales prediction per item using several Deep Learning models
*   Text classification - classical ML: text classification using classical ML approach
*   Anomaly detection: anomaly detection in time series using several ML and DL algorithms


Project folders contain:
*   Jupyter Notebook with the complete analysis
*   Python modules used in the notebooks
*   MLE folder contains README with detailed project description
